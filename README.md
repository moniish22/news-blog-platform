# News & Blog Platform

A full-stack publishing platform built with **Spring Boot 3, Spring Security 6, Hibernate/JPA, MySQL and Thymeleaf**.

Task: https://www.freeinternships.in/java-full-stack-internship/java-internship-online-free-news-blog-platform-jv-mc-002.php  (Task code JV-MC-002)

## Features

| Area | What it does |
|---|---|
| Roles | ADMIN, EDITOR, AUTHOR, READER with URL- and method-level protection |
| Articles | Create/edit/delete with a rich text editor (Summernote), sanitised HTML, auto slug, excerpt and reading time |
| Workflow | Draft -> Pending review -> Published / Scheduled / Archived. Authors submit; editors publish. Scheduled articles go live automatically |
| Organisation | Categories, tags (created on the fly), archive by month, featured stories |
| Discovery | Search across title, summary, body and tags; trending (last 7 days) and related articles |
| Comments | Nested replies, moderation queue, email to the author when a comment appears |
| Newsletter | Double opt-in, unsubscribe link in every email, subscriber management, send campaigns, email on new article |
| Analytics | Views, unique views, shares, average read time, bounce rate, 14-day chart, CSV export |
| Accounts | Register, login, forgot/reset password by email, profile, public author pages, reading list |

## Run it

1. Install **JDK 17+**, **Maven 3.9+** and **MySQL 8**.
2. Set the database credentials (defaults: user `root`, password `your_password`):
   ```bash
   export DB_USERNAME=root
   export DB_PASSWORD=your_mysql_password
   ```
   The database `newsblog_db` is created automatically and tables are generated by Hibernate.
3. Optional, for real emails (Gmail needs an **App Password** with 2-step verification on):
   ```bash
   export MAIL_USERNAME=you@gmail.com
   export MAIL_PASSWORD=your_app_password
   export MAIL_FROM=you@gmail.com
   ```
   Without these the app still works; failed emails are logged and skipped.
4. Start:
   ```bash
   mvn spring-boot:run
   ```
   Open http://localhost:8080

> IDE note: install the **Lombok** plugin and enable annotation processing (built in to IntelliJ IDEA 2020.3+, install it for Eclipse/STS).

## Project structure

```
src/main/java/com/newsblog
  config/       SecurityConfig, WebConfig, MailConfig, AppConfig (async, scheduling, demo data)
  controller/   Auth, Article, Category, Tag, Comment, Newsletter, User, Dashboard, Search, Admin
  service/      business logic (UserService, ArticleService, CommentService, NewsletterService, ...)
  repository/   Spring Data JPA interfaces
  model/        JPA entities and enums
  dto/          validated form objects
  util/         slugs, dates, HTML sanitising, article status
src/main/resources
  templates/    Thymeleaf pages (fragments/layout.html holds the shared header, footer, cards, pager)
  static/       css, js, images
```

## Database (11 tables)

`users`, `categories`, `tags`, `articles`, `article_tags` (join table), `comments` (self-reference via `parent_id`), `newsletter_subscribers`, `newsletters`, `article_analytics`, `saved_articles`, `article_views`.

Create the SQL dump required for submission after the first run:
```bash
mysqldump -u root -p newsblog_db > newsblog_db.sql
```

## How the two key features work

**Comments.** `CommentService.add` accepts comments only on published articles, strips HTML, and attaches replies to the top-level comment (two levels). ADMIN/EDITOR/AUTHOR comments are approved at once; READER comments are `PENDING` until a moderator approves them at `/moderation/comments`. Approval emails the article's author (async).

**Newsletter.** `NewsletterService.subscribe` stores the address with a random token and emails a confirmation link (`/newsletter/verify`). Only subscribers who are *active and verified* receive mail. The same token powers the one-click unsubscribe link in every email. Editors send campaigns from `/newsletter/send`; sending runs in a background thread and the result (sent count, status) is saved. Set `app.newsblog.newsletter.notify-on-publish=false` to stop automatic "new article" emails.

## Deployment notes

Any host that runs a Java 17 JAR and offers MySQL works (`mvn clean package`, then `java -jar target/news-blog-platform-1.0.0.jar`). Set these environment variables on the host: `DB_URL` (JDBC URL), `DB_USERNAME`, `DB_PASSWORD`, `BASE_URL` (your public URL, used in email links), `MAIL_USERNAME`, `MAIL_PASSWORD`, and `PORT` via `SERVER_PORT` if required. Never commit secrets.

## Security notes

BCrypt password hashing, CSRF protection on every form, HTML sanitised with jsoup before saving, comments stored as plain text, role checks in `SecurityConfig` and ownership checks in `ArticleService`, CSV export protected against formula injection.
